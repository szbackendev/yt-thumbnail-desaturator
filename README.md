# YouTube Thumbnail Desaturator

> **Language / Язык:** **Русский** | [English](README.en.md)

> [!NOTE]
> Проект разработан с участием ИИ-ассистентов. Исходный код доступен в репозитории; отдельная лицензия пока не добавлена.

Расширение для настольных Zen Browser и Firefox, которое уменьшает насыщенность обложек видео и Shorts на YouTube. Фильтры применяются к превью, а не к воспроизводимому видео.

Ползунок регулирует интенсивность цветов без изменения изображений на сервере YouTube.

---

## Возможности

- **Плавный регулятор насыщенности (0% – 100%)**:
  - `0%` — полностью чёрно-белые обложки (Monochrome / Grayscale).
  - `25% – 50%` — приглушённые тона; значение по умолчанию — `30%`.
  - `100%` — стандартная насыщенность YouTube.
- **Быстрые пресеты**: кнопки переключения в один клик (`0%`, `25%`, `50%`, `75%`, `100%`).
- **Точная настройка**: насыщенность задаётся ползунком или числовым полем.
- **RU / EN / Auto**: кнопка настроек в popup открывает выбор языка. Auto использует русский для русскоязычного браузера, иначе английский.
- **Общее включение**: главный переключатель отключает фильтры; обработка Shorts и восстановление при наведении управляются отдельно. По умолчанию все три переключателя включены.
- **Поддержка Shorts**: убавляет насыщенность превью Shorts в каруселях, ленте и поиске (можно отключить отдельным тумблером).
- **Цвет при наведении (Hover Restore)**: поддерживаемые статичные и движущиеся превью плавно возвращаются к полной насыщенности при наведении на карточку.
- **Обновление вкладок**: изменения в popup применяются к открытым вкладкам YouTube без перезагрузки; новые карточки подхватываются CSS-правилами.
- **CSS-фильтрация без сканирования DOM**: насыщенность задаётся CSS-переменной; обработка отдельных карточек в JavaScript не требуется. Использование GPU и затраты CPU зависят от браузера и оборудования.
- **Исключения**: активное видео, аватары каналов и баннеры должны оставаться цветными.
- **Сохранение настроек**: запись в `storage.sync` и `storage.local`; синхронизация между устройствами зависит от возможностей и настроек аккаунта браузера.
- **Необязательная поддержка проекта**: встроенная страница с внешней ссылкой DonationAlerts и публичными адресами кошельков. Расширение не обрабатывает платежи.

## Правила разработки и рабочий процесс (Git Workflow)

- **Основная ветка разработки**: вся разработка, исправление ошибок и внедрение нового функционала ведутся **строго в ветке `dev`**.
- **Релизная ветка `main`**: содержит проверенные релизные исходники. Прямые коммиты и push в `main` запрещены; конкретные серверные ограничения зависят от настроек GitHub.
- **Порядок работы**:
  1. Перед внесением любых изменений убедитесь, что вы находитесь в ветке `dev`:
      ```powershell
     git checkout dev
     ```
  2. Внесите изменения и запустите тесты:
      ```powershell
     python -m unittest discover tests
     ```
  3. Соберите релизный архив:
      ```powershell
     python package.py
     ```
   4. При подготовке обновления сначала выполните повышение версии в `dev`; команда запускает тесты, пересобирает XPI и откатывает манифест и архив при сбое:
      ```powershell
      python bump_version.py patch
      ```
   5. Зафиксируйте только файлы релиза и отправьте `dev` (добавленные тесты и другие изменения включите отдельно):
      ```powershell
      git add README.md README.en.md manifest.json yt-thumbnail-desaturator.xpi
      git commit -m "chore(release): prepare next version"
     git push origin dev
     ```
   6. Слияние в `main` производится через PR после CI и ручной проверки в Firefox/Zen. GitHub Release создаётся отдельно по тегу `v<version>`, совпадающему с манифестом и указывающему на коммит в `main`. Этот workflow не загружает дополнение в Mozilla.

### Проверки перед релизом

Работа расширения не требует Python, Node.js или npm. Для сборки нужен Python 3.12+; для полного набора тестов также нужен Node.js 24+. Установка сторонних пакетов не требуется. Команды выполняются из корня клонированного репозитория:

```powershell
python -m unittest discover tests -v
node --test tests/runtime.test.cjs
python package.py
```

Для дополнительных локальных CSS/UI-фикстур задайте `THUMBNAIL_TEST_BROWSER` полным путём к уже установленному Chromium и повторите тесты. Без переменной эти две проверки явно пропускаются. В чистом клоне также пропускается проверка `AGENTS.md`: это локальный файл, не входящий в репозиторий. Node.js-тесты используют модели WebExtension API; Chromium-фикстуры не проверяют интеграцию Gecko и текущую разметку живого YouTube.

Ручная проверка в Firefox/Zen:

1. `0%` / `100%`, ползунок, числовое поле и пресеты.
2. Главная, поиск, рекомендации рядом с видео и динамическая подгрузка карточек.
3. Цветное активное видео и Shorts, аватары и баннеры.
4. Общее включение, обработка Shorts, восстановление цвета и движущиеся превью при наведении.
5. Сохранение после повторного открытия popup и обновления страницы; изменение двух вкладок без перезагрузки.
6. RU / EN / Auto.

`python package.py --output <path>` собирает отдельный архив; родительская папка должна существовать. Тестовые сборки используют временные файлы и не перезаписывают рабочий XPI. Сборщик проверяет состав и ZIP-целостность, но не выполняет валидацию Mozilla и не подписывает пакет.

`.gitattributes` фиксирует окончания строк LF, чтобы исходники и XPI не зависели от автоматической конвертации строк в Git на Windows.

Если XPI загружен в Zen/Firefox как временное дополнение, браузер может блокировать его замену на Windows. Перед пересборкой выгрузите дополнение или закройте браузер; для разработки выбирайте `manifest.json`. При невозможности восстановления скрипт явно сообщает о неполном откате.

## Установка и использование

### Постоянная установка

Используйте опубликованную страницу дополнения на Mozilla Add-ons или подписанный Mozilla XPI. В Firefox подписанный пакет можно выбрать через `about:addons` → меню с шестерёнкой → **Установить дополнение из файла…**.

Архив `yt-thumbnail-desaturator.xpi` в репозитории и пакеты GitHub Actions **не подписаны Mozilla**. Они предназначены для временной проверки и отправки в Developer Hub, а не для постоянной установки в стандартный Firefox. Публикация в GitHub не заменяет проверку и подпись Mozilla.

### Временная загрузка в Zen / Firefox

1. Скачайте [исходники ветки main](https://github.com/szbackendev/yt-thumbnail-desaturator/archive/refs/heads/main.zip) и распакуйте архив либо клонируйте репозиторий.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **Загрузить временное дополнение…** (*Load Temporary Add-on…*) и выберите `manifest.json` в распакованной папке проекта.
4. Откройте YouTube. Уже открытые вкладки обновите после загрузки дополнения.
5. Нажмите значок расширения и настройте насыщенность. Для проверки `0%` без возврата цвета отключите восстановление при наведении.
6. Кнопка настроек в popup открывает выбор RU / EN / Auto.

Временное дополнение выгружается после завершения браузера. Его повторная загрузка не равнозначна проверке обновления постоянно установленного дополнения.

## Совместимость и ограничения

- Целевые платформы: настольные Zen Browser и Mozilla Firefox. В манифесте задан минимум Firefox `109.0`; это не означает проверку каждой версии начиная с 109.
- Floorp, Waterfox и другие Gecko-форки могут поддерживать дополнение, но отдельная проверка каждого форка не выполнена. Android и Chromium-браузеры не заявлены как поддерживаемые платформы.
- Разметка YouTube меняется и зависит от экспериментов сайта. Неподдерживаемые варианты карточек и конфликты со сторонними стилями требуют отдельной проверки.
- При `document_start` синхронно применяется значение по умолчанию `30%`; сохранённые настройки читаются асинхронно. Полное отсутствие переходного кадра не гарантируется.
- При запуске сохранённые ключи `storage.sync` имеют приоритет над локальным кэшем. Если запись в sync не удалась, но старые данные всё ещё читаются, следующий запуск может восстановить старое значение.
- CSS-фильтры не требуют JavaScript-сканирования каждой карточки. Затраты CPU/GPU зависят от браузера и оборудования; нулевая нагрузка не гарантируется.

## Приватность и разрешения

- `storage` — сохранение настроек; доступ к `*://*.youtube.com/*` — применение фильтров на YouTube.
- В манифесте указано `data_collection_permissions.required: ["none"]`. Расширение не содержит аналитики, телеметрии или удалённо загружаемого исполняемого кода.
- При переходе по внешней ссылке поддержки открывается сторонний сервис с собственными правилами обработки данных и платежей.

## Отправка обновления в Mozilla

1. В [Mozilla Developer Hub](https://addons.mozilla.org/developers/) откройте **существующее** дополнение и добавьте новую версию, не создавая новую карточку продукта.
2. Загрузите `yt-thumbnail-desaturator.xpi` из проверенного `main`. Версия должна быть выше ранее отправленных; Gecko ID сохраняется: `yt-thumb-desaturator@zen.browser`.
3. Заполните примечания к версии и ответьте на вопросы валидатора. Код не минифицирован; сборка только упаковывает локальные файлы. Если запрошены исходники, предоставьте их из соответствующего коммита вместе с командой `python package.py`.
4. Подпись, проверка и доступность обновления определяются Mozilla. Статус в Developer Hub является источником информации о публикации; успешный локальный тест не означает одобрения новой версии.

Порядок отправки описан в [официальной документации Mozilla](https://extensionworkshop.com/documentation/publish/submitting-an-add-on/).
