# YouTube Thumbnail Desaturator (Zen & Firefox Extension)

> **Language / Язык:** **Русский** | [English](README.en.md)

> [!NOTE]
> **AI Created**: Проект разработан с использованием возможностей современных ИИ-ассистентов для архитектуры, верстки и логики.

Легковесное расширение для браузера **Zen** (на базе Firefox / Gecko), предназначенное для точной настройки и приглушения насыщенности обложек (thumbnail) видео и Shorts на YouTube.

Позволяет устранить кричащий визуальный шум и кликбейт, делая ленту спокойной, эстетичной и минималистичной, не затрагивая при этом воспроизведение в активном плеере.

---

## Возможности

- **Плавный регулятор насыщенности (0% – 100%)**:
  - `0%` — полностью чёрно-белые обложки (Monochrome / Grayscale).
  - `25% – 50%` — мягкие, приглушённые тона (Detox mode).
  - `100%` — стандартная насыщенность YouTube.
- **Быстрые пресеты**: кнопки переключения в один клик (`0%`, `25%`, `50%`, `75%`, `100%`).
- **Два языка (Русский и English)**: выбор языка вынесен в отдельную страницу настроек браузера (`about:addons` -> Настройки расширения) без загромождения всплывающего окна.
- **Поддержка Shorts**: убавляет насыщенность превью Shorts в каруселях, ленте и поиске (можно отключить отдельным тумблером).
- **Цвет при наведении (Hover Restore)**: при наведении курсора на карточку видео насыщенность плавно возвращается до 100%, позволяя рассмотреть детали перед кликом.
- **Мгновенный отклик**: изменения в интерфейсе popup применяются во всех открытых вкладках YouTube в реальном времени без перезагрузки страниц.
- **CSS-фильтрация без сканирования DOM**: насыщенность задаётся CSS-переменной; обработка отдельных карточек в JavaScript не требуется. Использование GPU и затраты CPU зависят от браузера и оборудования.
- **Безопасные исключения**: активный видеоплеер (`<video>`) и аватарки каналов не затрагиваются.

## Правила разработки и рабочий процесс (Git Workflow)

- **Основная ветка разработки**: вся разработка, исправление ошибок и внедрение нового функционала ведутся **строго в ветке `dev`**.
- **Защищённая ветка `main`**: ветка `main` предназначена исключительно для проверенных, стабильных релизов. Прямые коммиты в `main` запрещены.
- **Порядок работы**:
  1. Перед внесением любых изменений убедитесь, что вы находитесь в ветке `dev`:
     ```bash
     git checkout dev
     ```
  2. Внесите изменения и запустите тесты:
     ```bash
     python -m unittest discover tests
     ```
  3. Соберите релизный архив:
     ```bash
     python package.py
     ```
  4. Зафиксируйте изменения и отправьте в репозиторий:
     ```bash
     git add .
     git commit -m "feat/fix: описание изменений"
     git push origin dev
     ```
  5. Слияние в `main` производится через PR после CI и ручной проверки в Firefox/Zen. Публикация релиза запускается тегом `v<version>`, совпадающим с манифестом и указывающим на коммит в `main`.

### Проверки перед релизом

Требуются Python 3.12+ и Node.js 24+; установка npm-пакетов не требуется:

```powershell
python -m unittest discover tests -v
node --test tests/runtime.test.cjs
python package.py
```

Для дополнительных локальных CSS/UI-фикстур задайте `THUMBNAIL_TEST_BROWSER` полным путём к установленному Chromium. Без переменной эти две проверки явно пропускаются. Фикстуры не проверяют WebExtension API Gecko и текущую разметку живого YouTube.

Ручная проверка в Firefox/Zen: Home → Search → Watch → Shorts, динамическая подгрузка, пресеты 0/100%, оба тумблера, hover, сохранение после повторного открытия popup, две вкладки и смена RU/EN/Auto. Активное видео, аватары и баннеры должны оставаться цветными. При холодном открытии синхронно применяется значение 30%; сохранённые настройки поступают асинхронно, поэтому полное отсутствие переходного кадра не гарантируется.

`python package.py --output <path>` собирает архив отдельно от рабочей копии. Тесты не перезаписывают релизный `.xpi`. `python bump_version.py patch` изменяет версию только в `dev`, проверяет проект и пересобирает архив; при ошибке восстанавливает прежние байты манифеста и архива.

## Инструкция по установке в Zen Browser

Так как **Zen Browser** основан на Firefox, установка выполняется штатным способом для Gecko-расширений:

### Способ 1: Временная загрузка (для разработки и тестирования)
1. Откройте браузер **Zen**.
2. В адресной строке введите:
   ```text
   about:debugging#/runtime/this-firefox
   ```
   *(или перейдите в Меню -> Инструменты -> Отладка дополнений)*.
3. Нажмите кнопку **«Загрузить временное дополнение…»** (*Load Temporary Add-on…*).
4. Выберите папку с расширением и там файл manifest.json.
5. Расширение мгновенно появится в панели расширений Zen!
6. Откройте [YouTube](https://www.youtube.com), нажмите на иконку расширения в панели инструментов и настройте комфортный уровень насыщенности.

Архив, созданный `package.py`, **не подписан Mozilla**. Для постоянной установки в стандартный Firefox требуется подписанный пакет; временное дополнение выгружается при завершении браузера.
