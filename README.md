# YouTube Thumbnail Desaturator (Zen & Firefox Extension)

> [!NOTE]
> **AI Created**: Проект разработан с использованием возможностей современных ИИ-ассистентов для архитектуры, верстки и логики.

Легковесное расширение для браузера **Zen** (на базе Firefox / Gecko), предназначенное для точной настройки и приглушения насыщенности обложек (thumbnail) видео и Shorts на YouTube.

Позволяет устранить кричащий визуальный шум и кликбейт, делая ленту спокойной, эстетичной и минималистичной, не затрагивая при этом воспроизведение в активном плеере.

---

## Возможности

- **Плавный регулятор насыщенности (0% – 100%)**:
  - `0%` — полностью чёрно-белые обложки (Monochrome / Grayscale).
  - `25% – 50%` — мягкие, приглушённые тона (Detox mode).
  - `100%` — стандартная насыщенность YouTube.
- **Быстрые пресеты**: кнопки переключения в один клик (`0%`, `25%`, `50%`, `75%`, `100%`).
- **Два языка (Русский и English)**: выбор языка вынесен в отдельную страницу настроек браузера (`about:addons` -> Настройки расширения) без загромождения всплывающего окна.
- **Поддержка Shorts**: убавляет насыщенность превью Shorts в каруселях, ленте и поиске (можно отключить отдельным тумблером).
- **Цвет при наведении (Hover Restore)**: при наведении курсора на карточку видео насыщенность плавно возвращается до 100%, позволяя рассмотреть детали перед кликом.
- **Мгновенный отклик**: изменения в интерфейсе popup применяются во всех открытых вкладках YouTube в реальном времени без перезагрузки страниц.
- **Нулевая нагрузка на процессор**: фильтрация выполняется на уровне CSS / аппаратного ускорения композитора браузера без тяжелых MutationObserver-циклов.
- **Безопасные исключения**: активный видеоплеер (`<video>`) и аватарки каналов не затрагиваются.

## Инструкция по установке в Zen Browser

Так как **Zen Browser** основан на Firefox, установка выполняется штатным способом для Gecko-расширений:

### Способ 1: Временная загрузка (для разработки и тестирования)
1. Откройте браузер **Zen**.
2. В адресной строке введите:
   ```text
   about:debugging#/runtime/this-firefox
   ```
   *(или перейдите в Меню -> Инструменты -> Отладка дополнений)*.
3. Нажмите кнопку **«Загрузить временное дополнение…»** (*Load Temporary Add-on…*).
4. Выберите папку с расширением и там файл manifest.json.
5. Расширение мгновенно появится в панели расширений Zen!
6. Откройте [YouTube](https://www.youtube.com), нажмите на иконку расширения в панели инструментов и настройте комфортный уровень насыщенности.
